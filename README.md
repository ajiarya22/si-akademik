# Sistem Informasi Akademik (SI-AKADEMIK)

Aplikasi Web Sistem Informasi Akademik sederhana berbasis PHP MVC Native.

## Fitur Aplikasi
- **Autentikasi**: System Login dan Logout berbasis Session.
- **Middleware**: Proteksi rute menggunakan `AuthMiddleware`.
- **Architecture**: Menerapkan pattern MVC dengan `BaseController`.
- **Repository Pattern**: Pemisahan logika database dengan `MahasiswaRepository`.
- **CRUD Mahasiswa**: Tampil, Tambah, Edit, dan Hapus Data Mahasiswa.
